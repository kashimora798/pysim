# CAD model credits

The GLB files in this directory are real electronic components converted from STEP
for web rendering by `tools/import_cad.py`.

- **Source:** KiCad official libraries — https://github.com/KiCad/kicad-packages3D
  (footprints: https://github.com/KiCad/kicad-footprints)
- **Licence:** Creative Commons CC BY-SA 4.0 with the KiCad libraries exception
  (https://www.kicad.org/libraries/license/). These converted files are
  redistributed library data in modified form and remain under CC BY-SA 4.0.
- **Attribution:** 3D models by the KiCad library contributors.

Per-model source files, sizes and terminal mappings: see `manifest.json`.
